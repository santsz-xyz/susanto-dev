## Overview
This is a lightweight, single-page static portfolio designed to showcase my technical projects, certifications, and experience in the Web3 space. The site highlights my transition from backend development to building high-performance decentralized systems, custom on-chain analytics bots, and smart contract integrations.

## Tech Stack
- **HTML5 & CSS3:** Custom styling without heavy frameworks for maximum performance and fast load times.
- **Vanilla JavaScript:** Minimal JS for dynamic date rendering.
- **Hosting:** Deployed via GitHub Pages.

## Core Focus Areas Highlighted
- **Rust & Solana:** Anchor framework, DeFi data extraction, and RWA (Real-World Asset) tokenization.
- **Python:** REST API integration for specific on-chain data tracking (e.g., Aptos).
- **Node.js & EVM:** Bridging traditional Web2 backend architecture with Web3 networks and oracle services (Chainlink).

## Running Locally
Since this is a static site with no build steps or heavy dependencies:
1. Clone the repository: `git clone https://github.com/santsz-xyz/susanto-dev.git`
2. Open `index.html` directly in your preferred web browser.
